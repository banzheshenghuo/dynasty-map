# 商代疆域完善（疆域精修 + 据点层 + 现代地名开关）（技术方案）

> 状态：执行中（三需求已实现，待部署确认）
> 日期：2026-09-30 →

## 背景

商·前1200 已上线（1abf76f），但商代表达仍是「一个推定包络色块」：

1. **疆域**：34 航点据点群推定包络，四至依据是商时期全图的一次粗读；且商代仅此一个断面（早商前1600 在二期方案剩余工作里）。
2. **无地点层**：商图的核心信息（都邑/方国/据点）没有在地图上表达，用户看到的只是一块色。
3. **古今对照缺地名**：现有「现代界线」开关只叠加国界省界线条，无现代地名——看上古地图时不知道色块对应今天的哪里。

本期把商代断面做完整：疆域可信度提升、据点/重点城市上图、并提供现代省/市/县地名对照开关。

## 技术方案

### 1. 商代疆域范围的确定

- **精修商·前1200 包络**：以已下载的谭图扫描件为据重新目读复核，素材新增使用
  `商时期中心区域图.jpg`（更大比例尺，王畿与核心据点密度远高于全图）：
  - 复核四至：西界陇山—秦岭、北界冀中、东南淮泗、南界盘龙城，逐段核对现有 34 航点；
  - 增补/修正航点，每点注释读图依据（沿用 `gen-hand-shang.mjs` 模式）；
  - `render-shang-preview.mjs` 自绘 BMP 目检形状（webview 渲染不可靠的既有结论）。
- **（待对齐）补商·前1600 断面**：成汤居亳时期，包络显著收敛（晋南豫西+郑亳为核心），
  据点取早商序列（亳/隞/相/邢/奄的前身）。若纳入，同步在二期方案的实施记录中注明
  「商前1600 移交本方案」，商代即早晚两断面收口，二期剩余夏/西周/春秋/战国。

### 2. 据点层（商代重点城市）— 新契约

- **契约**：`snapshots[].placesFile` 可选字段 → `geo/s{id}-places.json`：
  - FeatureCollection，`Point` 几何；
  - `properties`: `name`（据点名）/ `layer: "place"` / `kind`（枚举：都城|都邑|方国|遗址）
    / `today`（今地名，如「河南安阳」，tooltip 与古今对照用）/ `note`（可选一句话依据）；
  - 模式完全对齐 `-div.json`：懒加载、加载失败静默降级、上古断面之外任何断面可用
    （后世都城点位——咸阳/长安/大都等——为后续增量，本期只填商代数据）。
- **数据源**：谭图商图读图（沿用网格配准公式 `lon=(x−1385.4)/58.33+102.5`、
  `lat=45−(y−115)/66`，殷/周双锚点已验证）取都邑/方国点位；
  考古遗址类（盘龙城/郑州商城/偃师商城/小双桥/洹北/老牛坡/前掌大/苏埠屯/吴城/三星堆等）
  直接用现代考古坐标（学界共识，精度高于读图）。清单以谭图注记为准，读图时定稿。
- **渲染**：scatter 系列 + 常显楷体标签（复用 div-labels 的 hideOverlap 避让），
  kind 区分符号：都城=双环大点、都邑/方国=小点、遗址=空心点；tooltip 显示
  kind/今地名/note。默认显示（商代据点总量 ~20，密度低不碍事），不加独立开关。

### 3. 现代地名开关（省/市/县）— 新对照层

- **数据源**：阿里 DataV GeoAtlas 递归 `{adcode}_full.json`（已验证 properties 自带
  `center` 驻地坐标 / `level` / `acroutes` 层级链，无需算形心；市级文件 ~100KB）。
  全国 34 省 + ~340 市 + ~2800 县 ≈ 375 次请求（并发限 8，一次性几分钟）。
- **管线**：`tools/sources/fetch-modern-places.mjs` 下载提取（几何即弃，不缓存 raw），
  产出静态源 `tools/sources/modern-places.json`（~3200 点，约 300KB，入库）；
  `build-data.mjs` 从静态源产出 `data/geo/places-modern.json`（此后 build 不再联网）。
  许可与 provinces.json 同源（DataV），README 许可表更新说明。
- **契约**：FC of Point，`properties`: `name` / `layer: "modern-place"` / `adcode` /
  `level`（province|city|district）/ `province`、`city`（父级名，district 带两级，
  tooltip 显示「河南省 · 安阳市 · 滑县」）；坐标 2 位小数。
- **前端**：设置面板新增「现代地名」开关（默认关；与字号设置同区，不挤 header）。
  开启后懒加载点位，按缩放分层显示：低 zoom 只省名 → 中 zoom 省名+市名 →
  高 zoom 市县名（阈值执行时按视觉效果定）；`georoam` 监听 + 节流更新 series。
  样式走「墨=今」既有约定：小墨点 + 黑体细字 + 纸色描边，与历史政区楷体明确区分。
- **兜底**：若递归下载实测过重（>300MB 或频繁失败），降级方案为省级走 GeoAtlas +
  市县走开源整理数据集（如 kakuilan/china_area_mysql，高德坐标 2020 口径，页脚注明）。

### 风险与边界

- 据点层是契约新增，注意懒加载失败降级路径与政区层一致（console.warn，不白屏）。
- 现代县名 ~2800 个 label 同屏仅在高 zoom 且 hideOverlap 避让，性能需在低端机验证；
  必要时县级再按 viewport 内裁剪。
- 谭图读图坐标精度 ~0.2°（≈20km），据点定位以「示意图」口径呈现（页脚已注明口径，
  据点 tooltip 补今地名缓解）。
- 商前1600 若纳入：eras「商」分段自动从 −1600 起，时代条拉伸自愈，无额外适配。
