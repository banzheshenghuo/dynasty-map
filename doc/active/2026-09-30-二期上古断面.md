# 二期：上古断面（夏商周）— 技术方案

> 状态：执行中（商·前1200 已上线）
> 日期：2026-09-30 →

## 背景

时间轴起点原为秦·前221，缺上古两千余年。需求：补夏商周断面，数据质量需显著优于「凭印象手绘」。

调研结论（已与需求方对齐）：

- **无权威开放矢量数据**：CHGIS V6 从前221 起，先秦无数据；网上仅有在线浏览资源（CCAMC/太史古卷）与爱好者作品。
- **谭图第一册全图不画疆域色块**（夏/商/西周只有都邑点+方国注记+5°经纬网格；春秋/战国图才有诸侯国界线）。
- **决策：以谭其骧《中国历史地图集》为唯一主源**。点位、注记、国界忠实取自谭图；夏商西周疆域多边形为「据点群推定示意」（页脚与侧栏注明口径）。

## 技术方案

### 选型与思路

1. **扫描件获取**：CCAMC 在线版（`www.ccamc.co/chinese_historical_map/`，需浏览器 UA；图幅路径 `maps/atlas/{01,02,03}/{图名}.jpg`，册号与谭图原版不一致，需查页面取真实 src）。八张图幅已下载至 `tools/sources/raw/tan-atlas-vol1/`（gitignore，仅作读图参照不分发）。
2. **网格配准**：谭图自带 5° 经纬网。刻度条带裁块目读度数像素位置 → 线性拟合 `lon(x)`、`lat(y)` → 已知点反查验证（殷/周双锚点误差 <0.15°）。商图公式：`lon=(x−1385.4)/58.33+102.5`，`lat=45−(y−115)/66`。
3. **包络生成**：读图取据点群/界线 → 航点列表（注释标每点依据）→ Catmull-Rom 平滑 → `hand-*.json`（生成器脚本与源同目录）。
4. **管线接入**：SNAPSHOTS 断面表 + REGIME_COLORS + ERA_SUMMARY；**契约变更：`divisionsFile` 变为可选**（夏商西周无政区层），SCHEMA/validate 同步。
5. **形状验证**：webview 中 ECharts 渲染不可靠，用自绘 BMP（现代界参照 + 锚点标记）目检包络形状。

### 改动点

- `tools/sources/raw/tan-atlas-vol1/`：扫描件 + 裁块 + detect-grid.mjs（网格检测，信噪比不足弃用）+ render-*-preview.mjs（形状目检）
- `tools/sources/gen-hand-shang.mjs` → `hand-shang.json`
- `tools/build-data.mjs` / `tools/validate.mjs` / `data/SCHEMA.md`：divisionsFile 可选
- 每个新断面一条 SNAPSHOTS 记录 + 颜色 + 时代简介

### 风险与边界

- **过渡期时代条拉伸**：仅商·前1200 上线时 era「商」从 −1200 拉伸到 −221（eras 从断面聚合的既有行为），后续断面补齐自愈。
- 扫描件分辨率 2904×2033、对比度低，自动网格检测不可行（海洋底色淹没蓝线），目读刻度 + 锚点验证是当前最稳解。
- 上古事件上游无数据（data.js 从秦起），需本地事件源接入 build 的 EVENTS 段。
