# 渲染引擎迁移：ECharts geo → MapLibre GL JS（技术方案）

> 状态：已完结（2026-10-01 验收通过；移动端真机 WebGL 抽查为上线后遗留验收项）
> 日期：2026-10-01 → 2026-10-01

## 背景

现有渲染层为 ECharts `geo` 组件（Canvas 2D），随断面与图层增多出现结构性性能瓶颈：

1. **Canvas 2D 无 GPU 加速**：每次拖动/缩放全画布重绘（全部多边形 + 3000+ 现代地名点 + 全部注记重新光栅化）；单断面 GeoJSON 最大 ~935KB。
2. **文本避让是 CPU 逐帧算的**：4 个 series 挂 `labelLayout.hideOverlap`，roam 时反复触发，是拖动卡顿大头；低端安卓 webview 上尤甚。
3. **换断面全量重建**：`registerMap` + `setOption(notMerge: true)`，无增量路径。

选型结论（2026-10-01 与用户对齐）：**MapLibre GL JS**。WebGL 渲染、symbol 层 GPU 碰撞避让、`queryRenderedFeatures` 命中检测、`source.setData` 增量更新，四个痛点全部有原生解。备选放弃理由：deck.gl/L7 数据量远不到甜区且引入底图范式；d3+canvas 与 ECharts geo 同路线；echarts-gl 未 WebGL 化 geo。跨端已论证：小程序端届时单独适配（`data/` 复用），App 端 MapLibre Native 全家族样式互通——本方案把 style 写成独立 JS 模块（style.js 语义化函数，非散落字面量），为将来复用留口。

与在途方案《2026-09-30-二期上古断面》协同：彼为数据层补断面，此为渲染层替换，接口不变互不阻塞；上古断面（据点式疆域）在新渲染层验收清单中单列。

## 技术方案

### 选型与思路

- 引擎：`maplibre-gl`（v5，WebGL2 优先 / WebGL1 兜底）替代 `echarts`；移除 echarts 依赖。
- 数据零改动：GeoJSON 直接作为 GeoJSON source（引擎内置 geojson-vt 运行时切片），`fetch` + 懒加载 + 预取模式原样保留；`data/` 契约与 `tools/validate.mjs` 不动。
- 注记字体：MapLibre symbol 文字需 glyph PBF 或 **v6 新增的 style 级 `font-faces` 声明**（浏览器 FontFace API + CSS unicode-range 语法，分片懒加载）。选后者：**霞鹜文楷（LXGW WenKai，OFL 许可可分发，楷体风格承接现有 Kaiti 注记美学）** woff2 分片自托管 `data/fonts/lxgw/`（`tools/gen-fonts.mjs` 从 npm 包 lxgw-wenkai-webfont 生成，regular 97 片 4.7MB，按 unicode-range 懒加载）；`text-font` 统一 `LXGW WenKai`，缺字/加载失败逐级回落 `localIdeographFontFamily`（楷体系统栈）。（原方案为 PBF 管线，实施中因工具链受阻改道，见实施记录。）
- 接口不变：`src/map.js` 对 `main.js` 的 13 个导出签名全部保留，`main.js` / `index.html` / `sidebar.js` / `timeline.js` 不动。

### 存量逻辑迁移映射表

| ECharts 现状 | MapLibre 对应实现 |
|---|---|
| `registerMap` 合并五层 FeatureCollection | 5 个独立 GeoJSON source（neighbors/regime/provinces/divisions/modern），图层级显隐 `visibility` |
| `sentinelRegions` 4 哨兵 + 政权配色补丁 | fill/line 图层 paint 表达式 `match ['get','regime']` 着色；「现代界线」开关 → 邻国/省界/现代界三组图层 `setLayoutProperty('visibility')`（替代哨兵换色） |
| 政区虚线 `DIVISION_DASH` | `line-dasharray [3,2]`（像素单位，缩放视觉密度恒定，与原一致） |
| `labelLayout.hideOverlap` 避让 | symbol 原生碰撞检测（`text-allow-overlap:false` 默认），GPU 空间索引，免 JS 重算 |
| 注记形心定位（`labelPoint`/`ringCentroid` 等） | 计算逻辑保留，产出 GeoJSON 点要素喂 symbol source（文字避让需要点要素而非面内 label） |
| 王朝大字 / 政区注记 / 据点标注 / 现代地名 4 组 scatter-label | 4 组 symbol 图层，`text-font` 霞鹜文楷 / 无衬线区分，`text-halo-*` 对应原 `textBorderColor` |
| 标签四向轮转 `LABEL_POS` | 每要素写入 `properties.anchor`，`text-anchor: ['get','anchor']`（layout 属性 data expression；若实测不支持则退化为按 anchor 分组的四个图层） |
| 据点符号分级（circle/diamond/空心描边） | canvas 离屏预绘 5 种 SDF icon → `map.addImage`，symbol `icon-image` 按 `kind` match；都城光环为独立 icon 图层 |
| 事件点 scatter + tooltip formatter | circle 图层 + `map.on('click'/'mouseenter')`；tooltip 复用现有 `div-tip` DOM 与样式（含事件详情 HTML 结构） |
| 选中事件 `effectScatter` 涟漪 | 单点 DOM Marker + CSS 涟漪动画（一点成本可忽略，视觉等效） |
| 手写射线法 hover 政区（`findDivision`/`pointInRing`） | 删除，`queryRenderedFeatures` 命中检测；触屏不做悬浮跟随的现状保留（仅 tap 点选） |
| hover/选中政区 = region itemStyle 补丁两段式 setOption | `feature-state`（hover/selected）+ `fill-color`/`line-color` `case` 表达式；`promoteId` 以政区名为要素 id |
| `georoam` + `modernPlaceLevels` JS 分层重算（节流 120ms） | 声明式：省/市/县各一组 symbol 图层，`minzoom`/`maxzoom` 承担分层阈值（<2.2 省 / 2.2–4.8 省市 / ≥4.8 市县），三级开关 → `setFilter`；`move` 事件监听删除 |
| 换断面 `notMerge` 全量重建 + 160ms opacity 转场 | `source.setData` 增量 + paint `transition`（fill-color 等 300ms 渐变，政权换色天然平滑）；容器 opacity 转场保留 |
| `roam`/`scaleLimit`/`BOUNDS` | `dragPan` 默认手势 / `minZoom:1` `maxZoom:14` / `maxBounds` + 初始 `fitBounds(BOUNDS)` |
| 视野保持（切换断面继承 center/zoom） | `jumpTo({center,zoom})` 显式传入，`view` 参数语义不变 |
| 事件点击飞行 + 落定弹卡 | `flyTo`（自带缓动）+ `moveend` 后弹 tooltip；窄屏不弹卡逻辑保留 |
| 政区字号 9–20 滑杆 | `setPaintProperty('text-size')`（div-labels 与 places 图层联动，同现状） |
| `ResizeObserver → chart.resize()` | `map.resize()`，观察器保留 |

### 图层栈（自底向上）

1. neighbors fill+line（淡墨，随现代界开关）
2. regime fill+line（多政权 match 着色，weak 降透明；fill 有 transition）
3. provinces fill+line（淡墨，同 1）
4. divisions fill+line（朱砂虚线 + feature-state 高亮；fill 仅用于命中检测与高亮色，常时透明）
5. modern line（现代国界实线）
6. modern-places：省/市/县三组 symbol 图层（minzoom/maxzoom 分层 + filter 开关）
7. div-labels symbol（政区名，楷体，字号可调）
8. regime-labels symbol（王朝大字 26px，weak 15px）
9. places symbol（据点 icon+text，按 kind 分级）+ places-ring（都城光环）
10. events circle（事件朱砂点）
11. 选中事件 DOM Marker（CSS 涟漪）

### 改动点

- `package.json`：+`maplibre-gl`，−`echarts`；+`maplibre-font-maker`（devDep，仅字体管线用）
- `tools/gen-glyphs.mjs`（新增）：下载 LXGW WenKai TTF（gitignore）→ 生成 PBF → `data/glyphs/LXGW-WenKai/{start}-{end}.pbf`；README 许可表补 OFL 条目
- `data/SCHEMA.md`：注明 `glyphs/` 为渲染资源目录（工具生成、非数据契约、validate 豁免）
- `src/map.js`：整文件重写（接口签名不变），style 以语义化图层函数组织
- `src/style.css`：+涟漪 marker 样式；`maplibre-gl.css` 引入
- `index.html`：无改动（echarts 经 npm 引入，无 script 标签）
- `README.md`：架构图与技术栈描述更新（完结时）

### 风险与边界

- **字体分片**（原 PBF 风险已随方案调整消解）：woff2 分片 4.7MB 入库（Pages 限额内，懒加载按需请求）；现代地名由无衬线统一为楷体，古今字族对比暂失（后续可引 Noto Sans SC 分片恢复）。
- **text-anchor data expression 若不支持**：退化为四个按 anchor 分组的 symbol 图层（行为等价，图层数+3）。
- **低端安卓 webview（用户冻结机型）WebGL**：MapLibre v5 WebGL1 兜底，桌面先行验证；移动端实测留作上线后验收项，若个别机型黑屏需保留「降级提示页」的口子（本期不做）。
- **MapLibre 交互差异**：双击缩放/滚轮行为与 ECharts roam 接近但非逐像素一致；`doubleClickZoom` 关闭以避免误触（现状 ECharts 亦无双击放大）。
- echarts 移除后 `timeline.js`/`sidebar.js` 无依赖（已核实仅 map.js 引 echarts）。
- 断面切换动画从「换图重建」变「setData 渐变」，政区要素几何变化的过渡以 paint transition 表现（色渐变），几何本身瞬时切换——与现状视觉等价或更优。

## 实施记录

- 2026-10-01 立项并开始执行；glyph 产物路径定为 `data/glyphs/`（publicDir 即 data，零配置四环境一致），SCHEMA 增豁免说明。
- 2026-10-01 **字体方案重大调整：放弃 glyph PBF 管线，改用 MapLibre v6 `font-faces` 声明 + woff2 分片**。原因：① PBF 生成工具链全线受阻（`maplibre-font-maker-node` WASM 沙箱崩溃、官方 font-maker 已转 WASM 网页工具、PyPI 无包且直连 SSL 受阻）；② 发现 MapLibre v6 新增 style 级 `font-faces`（浏览器 FontFace API + CSS unicode-range 语法，分片懒加载），且 MapOptions 保留 `localIdeographFontFamily` 系统字体兜底。落地：`tools/gen-fonts.mjs` 从 npm 包 `lxgw-wenkai-webfont`（OFL）拷 regular 97 个 woff2 分片（4.7MB）至 `data/fonts/lxgw/` 并生成 `faces.json` 声明；`text-font` 统一 `LXGW WenKai`，缺字回落楷体系统栈。**与原方案差异**：现代地名原本用无衬线（PingFang），MapLibre text-font 只能引用声明的 fontstack，故统一楷体（古今字族对比损失，后续可引 Noto Sans SC 分片恢复）。
- 2026-10-01 修复三个「地图空白」级 bug（均 CDP console 定位）：① style 字段名 `fontFaces` → **`font-faces`**（style-spec 为 kebab-case，错误字段导致整个 style 被拒）；② `text-offset` 的 match 分支返回数组必须 `['literal', [...]]` 包裹（style-spec validateStyle 抓出）；③ **vite 不跟随 maplibre v6 worker 的 `new URL('./maplibre-gl-worker.mjs', import.meta.url)` 引用**，dist 缺 worker 文件 404 → Worker 加载失败 → 地图空白。修复：vite.config 加 `maplibreWorkerAssets` 插件发射 worker+shared 至 `assets/`（build），加 `optimizeDeps.exclude: ['maplibre-gl']`（dev，避免预打包丢 worker）。另发现 GeoJSON 瓦片化会序列化 properties，事件对象改以 `JSON.stringify` 挂 `__event`、点击/悬浮时解析。
- 2026-10-01 验收通过（vite build + validate.mjs + Chrome headless CDP 逐项回归）：
  - 渲染：商·前1600（据点式疆域+分级符号+楷体注记）、秦·前221（五德玄黑+41 郡虚线+郡名注记+「秦」大字）、唐·669（weak 吐蕃淡显+多政权）、清·1820、西汉·前87 全部正常，无豆腐块（楷体分片生效）；

  - 环境：dev 与 build 产物 console 均零错误；IAB webview 因 rAF 不触发（既有怪癖）不作为渲染验收环境，以 Chrome headless CDP 为准；

## 结论（2026-10-02 归档）

- **上线**：11defa7（迁移主体，含 `src/map.js` 整文件重写、vite worker 资产插件、霞鹜文楷分片管线）。数据层零改动（`data/` 契约与 validate 不动），`main.js`/`index.html` 对外零改动。
- **验收**：vite build + validate + Chrome headless CDP 逐项回归通过（渲染五断面/五类交互/双环境零 console 错误，明细见实施记录）。
- **收益落地**：四痛点全解（GPU 渲染、symbol 原生碰撞避让、setData 增量换图、queryRenderedFeatures 命中）；**附带消解已知问题「滚轮缩放不绕指针」**（ECharts layoutCenter 与 roam 锚定不兼容，MapLibre 原生绕指针，此前补偿失败的调研记录见 [商代完善归档](2026-09-30-商代疆域完善.md) 结论节）。
- **关键坑（后人必读）**：① style 字段是 kebab-case（`font-faces` 非 `fontFaces`，错一字整个 style 被拒、地图空白）；② data expression 里的数组常量须 `['literal', [...]]`；③ **vite 不跟随 maplibre v6 worker 的 `new URL(..., import.meta.url)` 引用**——build 产物缺 worker 404 即地图空白，已在 vite.config 内置发射插件 + `optimizeDeps.exclude` 双环境修复；④ GeoJSON source 会序列化 properties，挂事件对象须 `JSON.stringify` 编解码。
- **遗留**：移动端真机（低端安卓 webview）WebGL 抽查未做，个别机型黑屏时的「降级提示页」口子本期未留；现代地名与历史注记字族统一为楷体（原无衬线对比损失），后续可引 Noto Sans SC 分片恢复。
